# BidAI Pro

AI-powered construction bidding landing page, built as a lightweight static site for GitHub Pages.

## Publish with GitHub Desktop

1. Review the files in GitHub Desktop's **Changes** tab.
2. Enter a summary such as `Launch BidAI Pro website` and click **Commit to main**.
3. Click **Push origin**.
4. On GitHub, open **Settings → Pages** and set **Source** to **GitHub Actions** if it is not already selected.

After the first deployment finishes, the site will be available at:

`https://bidaipro.github.io/BidAIPro/`

## Local preview

Open `index.html` in a browser. No build step or dependencies are required.
